    Aide-mémoire des rotations

      P Passeur R4 C Central Pt Pointu L Libéro

      Flèche pointillée : où le joueur va ensuite (en réception, le départ de son élan d’attaque, pas le filet). Le petit numéro blanc est sa position de rotation.

      Placements repris de rotazionivolley (Maurizio Napolitano, version de 2019 sous licence Apache 2.0), lui-même basé sur VBRotations (Andy Edwards, licence Apache 2.0).

      4 contre 4

      Les équipes 4×4 sont indépendantes des équipes 6×6 : autres joueurs, autre nombre, autres présences. Postes : 4 (attaquant gauche), 2 (attaquant droit), Arr (arrière), P (passeur). Le temps de jeu se cumule d’un match à l’autre.
